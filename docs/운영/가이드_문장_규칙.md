# 가이드 문장 규칙 — 조사한 기준을 그대로 옮긴 것 (2026-11-20)

출처: 2026-11-18 조사 「한국어 웹 글 가독성 기준」의 종합 규칙표(Project 문서에 전문). 그때 여백 두 가지만 적용하고 **문장 규칙은 문서에만 남겨 뒀다** —
그래서 hyun 님이 화면을 캡처해 하나씩 짚어야 했다. 이 파일이 문장 규칙의 원본이다. AGENTS.md 「가이드 글 틀」과 겹치는 것은 AGENTS.md 가 이긴다.

쓰는 법: 글을 쓰거나 고칠 때 이 표의 「전 → 후」대로 한다. 「검사」 칸이 「없음」인 줄은 `check:geo` 로 옮길 대상이다(옮기면 칸을 고친다).

## 2. hyun 님이 짚어서 정한 규칙 (AGENTS.md 에 있고 `check:geo` 가 본다)

요약 문장은 사람 말로 · 어려운 말은 처음에 풀이 · 기간은 숫자로(6주) · 「~ 안쪽」 금지 · 단위는 km·kg·cm · FAQ 답 130자·4문장·굵게 1~3곳 · FAQ 논문 용어 금지 ·
딱지·[n]·※·따옴표·문장 속 → 금지 · 말끝 「권해요」 · 「N분 읽기」 금지 · 할 일이 먼저 · 작은 제목은 결론형

## 3. 용어 통일표 — 같은 뜻은 한 낱말로 (규칙 「같은 개념은 한 낱말로」「누구나 아는 말」)

검사(`check:geo`)가 이 표의 첫 칸을 읽어 막는다 — 「~」나 괄호가 든 칸은 사람이 본다. 「긴 달리기(롱런)」는 훈련 이름이라 풀이와 함께 쓰면 된다.
어느 말로 통일할지는 오픈채팅에서 **쓴 사람 수**로 정하는 것이 원칙이다. 표현별 사람 수는 아직 세지 않았다(원문이 노트북에 있다) —
아래는 hyun 님이 캡처로 짚은 말을 먼저 정한 것이고, 세고 나면 고친다.

| 쓰지 않는 말 | 이렇게 | 짚은 날 |
|---|---|---|
| 가장 긴 날 · 최장 거리 | (한 번에) 가장 길게 뛰는 거리 / 가장 길게 뛴 거리 | 11-20 |
| 걸음이 바뀔 만큼 · 걸음걸이가 바뀌면 · 자세가 바뀌거나 | 걸을 때도 아프면 | 11-18 · 11-20 |
| 그 단계를 한 번 더 · 그 단계를 반복 | 더 늘리지 말고 같은 양으로 다시 | 11-18 |
| 속도는 ~만큼이에요 | ~만큼 천천히 뛰어요 | 11-18 |
| 네 주 안쪽 · 여섯 주 | 4주만 쉬어도 · 6주 | 11-19 |
| 2마일 | 약 3.2km | 11-19 |
| 주 26km · 주간 거리 | 일주일에 26km · 일주일 거리 | 11-20 |
| 기준점으로 · 증가폭 · 보수적으로 | 기준으로 잡아요 · 얼마나 늘었는지 · 여유 있게 | 11-20 |
| 저희 제안 · 연구로 확인 (딱지) | 딱지 없이 문장의 세기로 | 11-18 · 11-20 |
| 무작위 시험 · 메타분석 · 중앙값 · 예후 · 유의하지 않았어요 | 시험 · 여러 연구를 모아 보니 · 절반이 ~ 안에 · 회복 · 뚜렷한 차이가 없었어요 | 11-19 |
| ~ 쪽 (걷기를 섞은 쪽, 권하는 쪽) | 걷기를 섞은 사람들, 권해요 | 11-19 |

## 4. 아직 검사가 안 보는 자리

2026-11-23부터 `check-geo` 「화면 글자 전수」가 app·components 의 모든 .tsx 와 신발 설명·신발 FAQ 를 본다(문장 규칙 · 「~니다」 · 근거 딱지 · 신발 화면 전문어).
아직 안 고친 파일은 그 검사의 `SCREEN_TODO`(.tsx)와 `DATA_TODO`(.ts 데이터)에 이유와 함께 있고, 고치면 목록에서 빼라고 실패한다. 새 틀로 안 바꾼 가이드 글은 `ROLLOUT` 이 맡는다.
한계: 백틱 문자열과 .ts 데이터 파일은 `DATA_TODO` 에 적은 것 말고는 읽지 못한다.
